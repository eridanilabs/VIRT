`/factory stop <n> [--orphaned]`: halt a run between stages. It never interrupts an agent partway through a stage. `<n>` may be the **issue or the PR** number, resolved the same way as [Approve](#approve) step 1; a run stopped in Spec has no PR yet, so a bare issue number is enough there.

1. The card must be in `Spec`, `Build`, `Review` or `Approve` (`node $B status`). Stop applies only in those columns. If the card is anywhere else, print its column and that `stop` applies only in Spec, Build, Review or Approve, then stop. Without `--orphaned`, for a **Backlog** card whose issue has a `factory/<n>-*` branch ([find the run's branch](#finding-a-runs-branch)), print instead: a Spec ahead run is in progress: `gh issue edit <n> --add-label factory:stop`, or `--orphaned` if its session died. One exception, with `--orphaned` only: a **Backlog** card whose issue has a `factory/<n>-*` branch is a [Spec ahead](#spec-ahead) run whose session died; go to step 3 for it, from `Backlog`.
2. **Without `--orphaned`**: add the label, `gh issue edit <n> --add-label factory:stop`, and nothing else. The session running that feature checks for `factory:stop` before every stage move ([Moving cards](#moving-cards)); when it sees it, it removes it and goes to Needs human with the reason "stopped by a human". `board.mjs` enforces the label as well: while it's there, `move` refuses any column but Needs human with `✗ stopped by a human (factory:stop)` (exit `3`), and `merge` refuses with the same reason, so the run can't merge or reach a later stage even if the session misses the check. The orchestrator then goes to Needs human with the reason "stopped by a human", and that move removes the label. Tell the user that, and that if no session is running that feature nothing will pick up the label: rerun with `/factory stop <n> --orphaned`. Then stop.
3. **With `--orphaned`**: no session is running that feature, so nobody will see the label. Work in its existing checkout: [find the run's branch](#finding-a-runs-branch), then [find the run's checkout](#finding-a-runs-checkout): the session's own worktree, as `workspace <n> --continue` decided. Remove the label if it's there (`gh issue edit <n> --remove-label factory:stop`), and go straight to [Needs human](#needs-human) from the card's current column, with the reason "stopped by a human", using the usual Needs human steps.

Either way, hand control back to the user with the [End-of-run summary](#end-of-run-summary): after step 2, a short one with the stop requested and the Next step; after step 3, the full Needs human summary.
